# ④ AI 전화 상담 — 조사·설계 (2026-11-25, 실제 발신 0회)

상태: **조사·설계만 완료. 실제 연동·테스트 통화는 미실행** — 유료 계정·발신번호 등록·결제가 필요하므로 대표 승인 전 진행 금지.

## 2. 법적 요건 (확인분 / 확인 필요)
- AI 기본법(2026-01-22 시행): AI 활용 사실 **사전 고지** 의무 → 통화 첫 문장에 "AI 상담원" 고지. 과태료 계도기간 1년 이상(korea.kr).
- 정보통신망법 제50조: 영리 목적 광고성 전화는 **사전 수신 동의**, 야간(21~08시)은 별도 동의 — 0050 `recontact_allowed`(opt_out·동의) 재사용. [법령 원문 재확인 필요]
- 발신번호: 해외 번호·임의 번호 표시 금지(발신번호 변작 금지) → 국내 등록 번호 필요. [통신사·Twilio 국내 번호 가능 여부 확인 필요]
- 녹음: 당사자 녹음 안내 + 개인정보 처리방침에 통화 녹음·국외 이전(해외 API) 고지 필요.

## 3. 구현 설계 (승인 후, 0052~)
- `core.ai_call_budget`: 월·일 **하드 한도(기본 0원 = 차단)**, 예약→확정 2단계(AI 비용 0030 패턴 재사용).
- `core.ai_calls`: 같은 연락처 **24시간 내 1회**, 동시 발신 잠금(연락처 HMAC advisory lock), 멱등 키.
- 발신 전 게이트: 수신 동의·opt_out·야간·한도·중복 → 하나라도 실패 시 발신 안 함.
- 사람 전환: AI가 "상담원 연결" 요청·인식 실패 2회 → 대표 콜백 일정(`api.recontact_schedule`) 등록.
- CRM: 통화 결과는 `lead_status_history`·`customer_timeline`에 가린 값만.

## 4. 승인 필요(대표)
1) 공급사 선택·유료 계정 결제 2) 국내 발신번호 등록 3) 테스트 번호(본인 번호) 1개 지정 4) 월 한도 금액.
