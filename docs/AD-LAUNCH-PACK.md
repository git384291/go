## 4. 예산 상한 — 강제 설정 가능 여부와 절차

**상한(승인됨):** 세금·수수료 포함 **하루 최대 10,000원, 최초 3일 총 30,000원.** 증액, 충전 승인, 자동 연장은 없다.

### 4-1. 강제 설정 가능 여부 — **현재 판정: 집행 불가(미확인)**
| 수단(후보) | 상한을 강제하는가 | 상태 |
|---|---|---|
| 캠페인 하루예산 | 하루예산을 넘는 과금 규칙(N7)을 모른다. 평균 일예산이거나 초과 소진이 허용되면 **강제 상한이 아니다.** | 미확인 |
| 선불 충전 잔액 | 잔액이 0이 되면 노출이 멈추고 음수·후불이 없다면(N8), 충전액(세금 포함)이 총액 상한이 된다. 충전은 지출 행위라 이번 승인 범위가 아니다. | 미확인 |
| 캠페인 기간(종료일) 설정 | 종료 시각에 노출이 멈추는지 확인이 필요하다. 3일 종료의 강제 수단 후보다. | 미확인 |
| 알림·수동 확인 | **강제 차단이 아니다.** 보조 수단으로만 쓴다. | — |

- 세금 계산: 부가세가 따로 붙는 구조(N9)라면 "설정값 × (1 + 세율) + 수수료 ≤ 상한"이어야 한다.
  - 예를 들어 세율이 10%이고 수수료가 없다고 **가정**하면, 하루 설정값은 9,090원 이하, 총 충전액은 세금 포함 30,000원 이하다.
  - 실제 세율·수수료는 N9를 확인한 뒤 다시 계산한다.
- 하루 상한과 총액 상한을 모두 강제할 수단이 확인되지 않으면 집행 불가를 유지한다.

### 4-2. 절차(강제 수단이 확인된 뒤에만 적용)
| 단계 | 조건 | 담당 |
|---|---|---|
| 시작 전 | 3절 증거 1~6 확인, 4-1 판정 "가능", 하루예산·종료일·충전액이 상한 이하인지 화면에서 확인, 소재 심사 통과 | 사용자(설정) + PM(승인) |
| 매일 | 정해진 시각에 매체 보고 비용(세금 구분)을 기록한다. 누적이 상한에 닿았거나 정책 위반·반려·이상 클릭이 보이면 캠페인을 끈다. 이 확인은 보조 감시이고 강제 차단이 아니다. | 사용자(중단 실행), PM(판단) |
| 3일 종료 | 시작 후 3일째 종료 시각에 캠페인 OFF(종료일 설정 + 수동 확인). **자동 연장 없음.** 계속 여부는 5절 결과를 보고 PM이 새로 결정한다. | 사용자 + PM |

## 5. 결과표(빈 양식)

- **기록 규칙**
  - 값이 없으면 `null`(미확인)로 둔다. 0은 실제로 0이 확인됐을 때만 쓴다.
  - 가상 예측이나 추정 매출로 채우지 않는다.
  - 클릭이나 접수처 이동을 접수로 세지 않는다. 측정하지 않은 이동은 추정하지 않는다.
  - 추적 픽셀, UTM, GA4/GTM, 고객 메시지 전송은 추가하지 않는다.
- **열 구분**
  - 매체 열: 매체 화면에서 고객정보 없이 확인되는 값
  - 총판 열: 총판이 확인해 준 값만, 확인 시각과 함께
