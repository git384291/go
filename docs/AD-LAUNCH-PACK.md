  - 가상 예측이나 추정 매출로 채우지 않는다.
  - 클릭이나 접수처 이동을 접수로 세지 않는다. 측정하지 않은 이동은 추정하지 않는다.
  - 추적 픽셀, UTM, GA4/GTM, 고객 메시지 전송은 추가하지 않는다.
- **열 구분**
  - 매체 열: 매체 화면에서 고객정보 없이 확인되는 값
  - 총판 열: 총판이 확인해 준 값만, 확인 시각과 함께
  - 단계 간 비교는 같은 코호트·귀속·중복 제거 기준일 때만 한다(REVENUE-FIRST-LAUNCH 4절).

## 6. 남은 결정(현실적으로 다음에 필요한 것)
1. **엄격 상한(J6):** 현재 후보로는 불충족이다. 매체 쪽 강제 수단을 공개자료로 더 찾는다(4-1-1). 없으면 집행 불가를 유지한다. 그 뒤의 예산 결정은 사용자만 한다(자동 요청 없음).
2. **아직 미확인인 공개 규칙:** N2(통신·딜러 업종 요건), N9-2 일부(비용 표시·실제 세율·세액·실계정), N9-3 일부(결제 수수료·실제 공제액), N3 통신사 상표 사용 허락·"공식" 지위, N5 운영자 불일치 예외·총판 직접 경로 개별 허용, 파워링크 엄격 지출 한도. S8·S9는 N3·N5의 일반 기준 일부만 확인한다. PM·Claude가 공개자료로 조사한다. 사용자에게 공식 문서를 열어 달라고 요청하지 않는다.
3. **사용자 실계정·총판 쪽(J1·J2·J4·J5, 증거 2~6):** 이미 전달된 요청의 결과를 기다린다. 중복 발송하지 않는다.
4. **사이트 개인정보 공개(J3):** 승인 없음. 공개하지 않는다.
