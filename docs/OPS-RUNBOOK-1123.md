## 2. 대표용 초보자 안내 (지금 할 수 있는 것)

### 2-1. 상호·상표 검토(순서 1)
1. 키프리스(kipris.or.kr) 접속 → 상표 검색창에 `바른통신` 입력.
2. 같은 이름·비슷한 이름이 통신 관련 분류(예: 전기통신업)로 등록돼 있는지 결과 화면을 캡처한다.
3. 판단이 어려우면 변리사 상담을 받는다(법률 판단은 Claude·PM이 대신할 수 없다).
4. 캡처와 "사용할 표기"를 PM에게 전달한다.

### 2-2. 고지문·처리방침 자료 준비(순서 2)
1. 총판에 "고객 개인정보를 총판에 넘길 때 고객 동의 문구·보관 기간 기준"을 요청해 받는다.
2. 아래 4가지를 적어 PM에게 전달한다: ① 개인정보를 받는 사람(대표 본인 이름, 사업자 없음) ② 받는 항목(이름·휴대폰·관심 상품·연락 희망 시간, 신청 시 주소·이메일) ③ 보관 기간 ④ 총판에 넘기는 항목.
3. 개인정보보호위원회 '개인정보 처리방침 작성 지침'을 참고한다(최종 문구는 PM 검수).

### 2-3. Google 테스트 계정 만들기(순서 6, 광고비 0원)
1. 새 Google 계정(업무용)으로 Google Ads **관리자(MCC) 테스트 계정**을 만든다(Google Ads API 문서 'Test accounts' 안내를 따른다).
2. 그 안에 하위 테스트 계정을 만들 때 **통화 KRW, 시간대 (GMT+09:00) 서울**을 고른다.
3. 테스트 계정은 광고가 게재·청구되지 않는다(Google 공식). 결제 수단을 넣지 않는다.
4. OAuth 클라이언트 ID·리프레시 토큰 발급은 Claude가 단계별로 안내한다. **값은 채팅·GitHub에 붙여 넣지 않는다.**

### 2-4. 운영 키 생성(순서 4)
- 키 값은 대표 PC 터미널에서 만들고 Vercel 환경변수 화면에 직접 붙여 넣는다. 만드는 명령은 Claude가 따로 안내한다.
- 키 값을 카카오톡·채팅·GitHub·메모장 공유 폴더에 남기지 않는다. 비밀번호 관리자에만 보관한다.
